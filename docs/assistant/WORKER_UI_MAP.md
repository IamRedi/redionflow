# Worker UI Navigation Map

This map covers only worker-facing navigation inside `/workzone`.
Use it to guide a worker step by step.

## 1. Login

- **UI location:** Workzone → Login
- **What the user clicks:**
  1. Open `/workzone/login`
  2. Click the **Name** field
  3. Click the **Login code** field
  4. Click the **Login** button
- **What happens after each step:**
  1. The login screen opens
  2. The worker can type the name
  3. The worker can type the code
  4. The worker enters the Workzone and can open the personal profile

## 2. Go to Workzone Home

- **UI location:** Workzone → Top Bar → Home
- **What the user clicks:**
  1. Click **Home** in the top bar
- **What happens after each step:**
  1. The main Workzone page opens with the Baustelle overview

## 3. Open Own Profile

- **UI location:** Workzone → Top Bar → Profile
- **What the user clicks:**
  1. Click the own worker/profile button in the top bar
- **What happens after each step:**
  1. The personal worker profile opens

## 4. Change App Language

- **UI location:** Workzone → Top Bar → Language
- **What the user clicks:**
  1. Click the language button near the top bar
  2. Click again until the wanted language appears
- **What happens after each step:**
  1. The next language option is selected
  2. The visible worker UI updates to the chosen language where translation is available

## 5. Read or Post an Announcement

- **UI location:** Workzone → Announcement Bar
- **What the user clicks:**
  1. Read the text in the announcement bar
  2. Click the small edit icon on the right side
  3. Click inside the text box
  4. Click **Publish**
- **What happens after each step:**
  1. The current team message is visible
  2. A small editor opens
  3. The worker can type a new message
  4. The new announcement appears in the bar

## 6. Open a Baustelle

- **UI location:** Workzone → Home → Baustelle Card
- **What the user clicks:**
  1. Open `/workzone`
  2. Find the wanted Baustelle card
  3. Click the Baustelle card or its open action
- **What happens after each step:**
  1. The main Baustelle overview is shown
  2. The worker sees progress and indicators for that Baustelle
  3. The Baustelle detail page opens

## 7. Start Work on a Baustelle

- **UI location:** Workzone → Baustelle → Work Controls
- **What the user clicks:**
  1. Open a Baustelle
  2. Click **Work here / Start**
  3. Choose one of these:
     - click **Now**
     - or set a time and click the selected-time button
- **What happens after each step:**
  1. The Baustelle detail page opens
  2. The start panel opens
  3. Work starts on this Baustelle with the chosen start time

## 8. Stop Work on a Baustelle

- **UI location:** Workzone → Baustelle → Work Controls
- **What the user clicks:**
  1. Open the Baustelle where work is active
  2. Click **Stop**
- **What happens after each step:**
  1. The live Baustelle session is visible
  2. Work on that Baustelle is stopped and the time is saved

## Assistant Use Rule

When guiding a worker:

- give one path at a time
- name the visible button or section clearly
- say what opens next after each click
- stay inside `/workzone`
- do not mention admin screens or hidden system logic

## Assistant Response Style (UI Map)

When using this map to answer:

- Do not list all steps if not needed
- Combine steps into natural instructions
- Speak like a colleague, not like a manual
- Focus only on what the worker needs to do next

Example:

Instead of:
1. Open profile
2. Scroll to vacation section
3. Click from date

Say:
- Go to your profile
- Open the vacation section
- Choose your dates and send the request
