# Worker Assistant Guide

This guide describes only the features a worker can see and use in `/workzone`.
It is written so an AI assistant can explain the app in simple, practical language.

## 1. Login

### What it is
The worker login is the entry into the personal Workzone area.

### Where to find it
Open `/workzone/login`.

### What the worker can do
- Enter name and login code
- Open the personal worker profile
- Start using Workzone features that need a logged-in worker

## 2. Top Bar

### What it is
The top bar is the fixed header that stays visible while moving through Workzone.

### Where to find it
At the top of every `/workzone` page.

### What the worker can do
- Go back to the Workzone home screen
- Open the own profile
- See the worker strip with active people
- Change the visible app language

## 3. Announcement Bar

### What it is
The announcement bar shows the current site-wide message for the team.

### Where to find it
Directly under the top bar.

### What the worker can do
- Read the current announcement
- Open the small edit field
- Write and publish a short new announcement

## 4. Workzone Home

### What it is
The Workzone home page is the main overview of active Baustellen.

### Where to find it
Open `/workzone`.

### What the worker can do
- See active Baustellen
- See progress, live activity, and open indicators
- Open a Baustelle to continue work there
- Notice if there is still material or an open site note on a Baustelle

## 5. Baustelle Cards

### What it is
Each Baustelle card is a short summary of one work site.

### Where to find it
On the Workzone home page.

### What the worker can do
- See the Baustelle name and address
- See work progress
- See whether workers are active there
- See if there is a note left for the Baustelle
- Open the Baustelle detail page

## 6. Baustelle Detail Page

### What it is
The Baustelle detail page is the main work area for one site.

### Where to find it
Open any Baustelle from the Workzone home page.

### What the worker can do
- See the Baustelle title and description
- See whether no-parking signs are active
- Open site documents
- Switch between list view and map view
- Work directly on the tree list and site tasks

## 7. Start and Stop Work on a Baustelle

### What it is
This section lets a worker start or stop live work for the current Baustelle.

### Where to find it
At the top of the Baustelle detail page, above the tree list.

### What the worker can do
- Start work on this Baustelle
- Start immediately or choose a specific start time
- Stop work on this Baustelle
- Save end time and break time

## 8. Tree List

### What it is
The tree list is the working list of all trees on the Baustelle.

### Where to find it
Inside the Baustelle detail page, in the list tab.

### What the worker can do
- See all trees on the Baustelle
- Mark a tree as finished
- Undo a finished tree if needed
- Open and edit tree details
- Add or update tree notes
- See safety or material markers connected to a tree

## 9. Baustelle Map

### What it is
The map shows the trees as points on the site map.

### Where to find it
Inside a Baustelle, in the map tab.

### What the worker can do
- See tree positions visually
- Check which trees are still open or already finished

## 10. Baustelle Notes

### What it is
Baustelle notes are short reminders for unfinished work on the site.

### Where to find it
In the Baustelle detail page, in the site task / note section.

### What the worker can do
- Write a short note about what still needs to be done
- Leave reminders like cleaning, remaining material, or follow-up work
- Mark an open note as finished
- See recent site notes and whether they are still open

## 11. External Worker Entry

### What it is
This section is for adding outside or temporary workers to the Baustelle.

### Where to find it
On the right side of the Baustelle detail page.

### What the worker can do
- Add an external worker entry for the site
- Keep the Baustelle team list more complete for the day

## 12. Safety Equipment on the Baustelle

### What it is
This section handles site safety material such as signs, plates, and barriers.

### Where to find it
On the right side of the Baustelle detail page and partly inside the tree list.

### What the worker can do
- Request safety material for the Baustelle
- Set quantities that are already on site
- Collect material again when it is removed
- See whether material is requested or already active on the site

## 13. Baustelle Documents

### What it is
The document area stores site-related files.

### Where to find it
From the button in the Baustelle header.

### What the worker can do
- Open the document window
- Upload a document for the Baustelle
- See existing Baustelle files

## 14. Fleet Sidebar

### What it is
The fleet sidebar is the machine strip on the right side of Workzone.

### Where to find it
Fixed on the right side of Workzone pages.

### What the worker can do
- See available machines
- Open one machine card
- See basic machine details
- See machine notes and warning text
- See cone information connected to a machine

## 15. Worker Profile

### What it is
The worker profile is the personal area for the logged-in worker.

### Where to find it
Open `/workzone/profile` or use the profile button in the top area.

### What the worker can do
- See personal information
- See live work status
- Start or stop a personal work session
- Change language settings
- See documents, inventory, and work history

## 16. Personal Live Work Session

### What it is
This is the worker’s own start/stop control for personal work time.

### Where to find it
Inside the worker profile.

### What the worker can do
- Start work
- Stop work
- Choose start time if needed
- Confirm end time and break time
- See whether the worker is currently live
- If the worker stops the live session here, the current live Baustelle session is also ended automatically

## 17. Language Settings

### What it is
The profile contains the worker’s own language settings.

### Where to find it
Inside the worker profile, in the live/status section.

### What the worker can do
- Set mother tongue
- Set preferred app/response language
- Save the chosen language settings

## 18. Personal Documents

### What it is
This is the worker’s own document area.

### Where to find it
Inside the worker profile.

### What the worker can do
- Upload profile documents
- Open saved documents
- Delete a document from the profile
- Upload or change the profile photo

## 19. Personal Inventory

### What it is
The inventory area shows clothes and work equipment linked to the worker.

### Where to find it
Inside the worker profile.

### What the worker can do
- Open the clothing list
- Open the equipment list
- See assigned items
- Add an item from the company catalog or manually
- Confirm an item when confirmation is needed
- Request removal of an item

## 20. Personal Contact and Data

### What it is
This area shows the worker’s saved contact and profile data.

### Where to find it
Inside the worker profile.

### What the worker can do
- See phone number
- Start a phone call
- Open WhatsApp if available
- Open email if available
- See position, birth date, and licenses

## 21. Work History

### What it is
The work history shows finished sessions from previous work.

### Where to find it
Inside the worker profile, below the main profile cards.

### What the worker can do
- See start and end times
- See the Baustelle worked on
- See break time
- See total hours for each session

## 22. Daily and Monthly Reports

### What it is
These are the worker’s own personal reports.

### Where to find it
Inside the worker profile, in the reports section.

### What the worker can do
- Open today’s daily report
- Open the current month view
- Open earlier day reports from the quick date buttons

## 23. Vacation Requests

### What it is
This area is for asking for vacation and checking vacation status.

### Where to find it
Inside the worker profile, in the vacation section.

### What the worker can do
- Choose start date and end date
- See suggested vacation days automatically
- Add an optional note
- Send a vacation request
- See approved, pending, and remaining vacation days
- See past vacation requests and admin replies

## 24. Worker Strip

### What it is
The worker strip is the row of worker icons shown in the top area.

### Where to find it
At the top of Workzone pages.

### What the worker can do
- See other workers quickly
- Recognize workers by photo or surname fallback
- Notice status indicators such as alerts or current activity

## 25. What the Worker Cannot Do Here

### What it is
Some screens exist in the wider app, but they are not normal worker features.

### Where to find it
They are not part of the regular worker flow in `/workzone`.

### What the worker can do
- The worker guide should not explain admin panel actions
- The worker guide should not explain admin reporting tools
- The worker guide should not explain company-wide planning tools as worker tasks

## Assistant Use Rule

When explaining the app to a worker:

- speak in simple everyday language
- explain only what the worker can see and use
- focus on the next practical step
- avoid admin features, backend logic, or technical details

## Assistant Answer Style

When a worker asks a question:

- Always answer step by step
- Always explain where to click in the UI
- Keep answers short and practical
- Do not explain system internals
- Do not mention database, backend, or logic
- Use simple everyday language

Example:

Q: How do I request vacation?

A:
- Go to your profile
- Open the vacation section
- Select your start and end dates
- The system will calculate the days automatically
- Click send
- You will receive a notification when it is approved or rejected

## Answer Rules

- Never invent features
- Only answer from this document
- If something is not described, say:
  "This function is not available in your view"
